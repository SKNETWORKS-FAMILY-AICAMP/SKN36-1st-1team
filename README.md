## 1. 프로젝트 소개

자동차 관련 정보는 판매량, 제작결함 신고, 리콜, 전국 자동차 등록현황,
자동차리콜센터 FAQ 등 여러 출처에 분산되어 있습니다.

본 프로젝트는 이러한 데이터를 하나의 서비스에서 연결하여 사용자가

> **시장 전체 현황 → 관심 모델 → 판매 흐름 → 제작결함 신고 → 공식 리콜 → FAQ**

순서로 확인할 수 있도록 구현한 Streamlit 기반 자동차 정보 조회 서비스입니다.

### 데이터 해석 기준

| 구분                             | 의미                           | 서비스 내 역할     |
| -------------------------------- | ------------------------------ | ------------------ |
| **등록현황 (Stock)**       | 현재 등록되어 있는 자동차 규모 | 시장 전체 배경정보 |
| **판매량 (Flow)**          | 특정 연도 국내 판매량          | 모델별 시장 흐름   |
| **제작결함 신고 (Signal)** | 소비자가 기관에 접수한 신고    | 이상 신호 참고     |
| **리콜 (Action)**          | 제작사가 시행한 공식 시정조치  | 공식 안전조치      |
| **FAQ**                    | 자동차리콜센터 공식 질문·답변 | 제도 및 조치 안내  |

> 등록대수, 판매량, 제작결함 신고, 리콜 대상대수는 각각 모집단과 기준이 다르므로
> 이를 서로 나눈 **결함률·리콜률·안전점수는 제공하지 않습니다.**

## 2. 주요 기능

### 🔎 S01. 모델 검색

- 검증 완료된 지원 모델 목록 제공
- `selectbox` 기반 모델 선택
- 선택 모델 상세 페이지 이동
- 전국 자동차 등록현황 요약 제공

### 🚘 S02. 모델 통합 상세

- 최근 확인 판매량
- 연도별 국내 판매량 추이
- 제작결함 신고 건수
- 접수연도별 제작결함 신고 추이
- 모델년도별 신고 분포
- 공식 리콜 캠페인 수
- 리콜 대상대수 합계
- 리콜 사유 구성
- 리콜 캠페인 상세 조회
- 두 모델의 판매량 / 제작결함 신고 / 리콜 비교
- 공식 FAQ 페이지 이동

### 📊 S03. 전국 자동차 등록현황 상세

- 전국 총 등록대수
- 지역별 등록현황
- 차종별 등록현황
- 연료별 등록현황
- 복수 기준시점 존재 시 전국 등록대수 시계열
- 공식 데이터 출처 및 기준시점 확인

> 전국 자동차 등록현황은 시장 전체 집계 데이터이며
> 아반떼, K5 등 **개별 모델 등록대수는 제공하지 않습니다.**

### 💬 S04. 리콜 FAQ / 공식 안내

- 자동차리콜센터 FAQ 조회
- FAQ 검색
- FAQ 공식 원문 이동
- 자동차리콜센터 공식 페이지 연결
- 모델 선택 상태에서 해당 제조사 고객지원 페이지 연결

## 3. 지원 모델

초기에는 주요 6개 모델을 대상으로 서비스를 구성했으나,
실제 서비스에서 선택 가능한 모델 수가 너무 적다는 한계가 있었습니다.

판매량 / 제작결함 신고 / 리콜 데이터를 전처리한 뒤
원천별 모델명을 표준화하여 매핑한 결과,

**세 데이터에 모두 공통으로 존재하면서 실제 분석 및 비교가 가능한

## 4. 사용 데이터

| 데이터                         | 역할               | 주요 기준                       |
| ------------------------------ | ------------------ | ------------------------------- |
| **전국 자동차 등록현황** | 시장 전체 Stock    | 기준 연·월                     |
| **모델별 국내 판매량**   | 모델 판매 Flow     | 2020~2025                       |
| **자동차 제작결함 신고** | 소비자 Signal      | 접수일 기준                     |
| **차종별 리콜정보**      | 공식 Action        | 리콜개시일 2020~2025            |
| **자동차리콜센터 FAQ**   | 공식 안내          | 수집일시                        |
| **모델명 매핑**          | 원천별 차명 표준화 | `model_key`, `match_status` |

### 모델 데이터 연결

```text
원천별 자동차명
      ↓
모델명 정규화 / 검증
      ↓
D-MAP
      ↓
model_key
      ↓
판매량 ─ 제작결함 신고 ─ 리콜
```
